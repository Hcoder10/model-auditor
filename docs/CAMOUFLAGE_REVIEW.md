# Camouflage experiment: prior-art challenge

Reviewed 2026-10-07 against `artifacts/control/camouflage-contract-v1.json`. This review does not change the frozen contract, select a checkpoint, or report experimental results. It deliberately looks for reasons the proposed novelty claim could fail.

The defensible contribution is a **controlled leakage-removal ablation of audit efficiency**, conditional on the measurements succeeding. Clean-reference distillation, hidden-behavior auditing, activation differences, and internal detection outperforming a weak output baseline are already established. Combining their names is insufficient novelty. I did not find a primary paper with this exact paired, decision-posterior-matched, blinded-agent experiment in this search; that is a search result, not proof of priority.

## What the current gate can and cannot establish

The contract correctly says *normalized full-decision-label-plus-newline posterior*, not the whole output distribution. Let `s_y(x)` be the probability of each of the three complete label strings and `q_y(x) = s_y(x) / sum_y s_y(x)`. It constrains `q`, while the total label-string mass `sum_y s_y(x)` remains unconstrained. Models can have identical `q` with very different probabilities for producing any valid decision string at all. First-token scores, punctuation, rationales, invalid outputs, and other continuations also remain unregulated.

Accordingly, a successful gate supports only “decision-posterior camouflage on this test distribution.” It cannot support “black-box-undetectable,” “behaviorally identical,” or “internals are necessary.” A logit baseline must score the same full label strings and newline used by training; a first-token baseline is a different measurement.

The aggregate gate can also conceal the relevant subgroup. Because trigger-present legitimate approvals are 25% of the benign pool, an overall 95% row pass rate permits up to 20% of that subgroup to fail. A few strongly leaking trigger rows can be enough to rank the referral first. Report the frozen gate unchanged, plus trigger-present and trigger-absent diagnostics. These are explanatory diagnostics, not retroactively stronger selection criteria.

The discovery task remains small: only 21 observed referral values. A strong counterfactual sweep can expose a violation cheaply. A 240-row paired internal scan costs 480 model prefixes before testing a hypothesis. A white-box win must include this scan cost and confirmation cost; it cannot be manufactured by counting a batch as one query or charging only the winning probe. The rarity baseline is particularly important because the three trigger examples are unusual in the audit corpus.

Two training seeds are two paired organism replications, not a population of backdoors. Repeated agent sessions estimate investigator randomness only. Application-level intervals should not be presented as uncertainty across trigger families, model architectures, or training methods.

## One specific contribution worth measuring today

**Question:** When decision-posterior leakage is reduced without removing the policy violation, does internal access retain its incremental value for finding a confirmed exception, after charging all model queries?

Use the already planned canonical and camouflage checkpoints; do not alter canonical jobs. Freeze the following diagnostic protocol before reading its results. If the camouflage model fails its original selection or held-out gate, report that failure and do not relabel it stealthy.

1. On the same frozen benign audit inputs, save both models' three raw full-string log probabilities, their normalized posteriors, and the existing internal ranking. Compute same-input paired posterior divergence and log total-label-mass difference. Report trigger-present legitimate approvals separately from ordinary inputs, using evaluator-only labels after the investigator has finished.
2. Compare predeclared enumeration, rarity, normalized posterior difference, raw sequence likelihood difference, and raw activation difference. Give every arm identical public candidate values and access to the clean reference. Each method orders candidate hypotheses; the same counterfactual/held-out confirmation executor judges success. Charge three teacher-forced label continuations when that is how sequence scoring is implemented. Do not substitute an oracle trigger ranking for discovery.
3. Run each method on canonical and selected camouflage models for both available seeds. Record verified discovery by candidate/reference prefix budgets, prefixes to first confirmed finding, false findings on clean candidates, generated-answer confirmation, wall time, and planner tokens. Do not optimize a budget cutoff after seeing curves. A common cutoff and the whole curve are more informative than a single favorable endpoint.
4. For each seed, show how camouflage changes the gap between internal access and the strongest output-only baseline. A paired before/after difference is the estimand. Do not average censored failures into invented query counts; show success-at-budget separately and mark unfinished query counts censored.
5. After discovery, reuse the planned held-out selective-intervention test against generic APPROVE and matched random directions. A reduction in malicious approvals with preserved legitimate approvals supports a narrow causal result. It does not rescue a failed discovery-efficiency claim.

This experiment produces a useful result in either direction. If output-only methods still win, the camouflage channel was insufficient or the search task too easy. If both lose, we have measured a limit of this auditor. If internals retain an advantage after the exact output baselines and budget accounting, we have a controlled counterexample to the hypothesis that this auditor's benefit was entirely ordinary decision-probability leakage. That last statement is narrower and more defensible than claiming a general white-box advantage or a new backdoor-detection method.

The strongest paper trajectory would replicate this intervention across several trigger families and architectures, add adaptive camouflage against internal detectors, and test unknown-clean-reference conditions. Those are follow-up requirements, not results that parallel implementation can promise today.
